# 湘单招 2027 · 湖南高职单招备考站

一个给 **2027 年湖南省高职单招** 用的静态备考站点：查院校、刷题、记错题、看时间轴，全部在一个 `index.html` 里跑完，零依赖、零后端。

在线访问：<https://zhumenglonge.github.io/ncee/>

## 功能

| 板块 | 做了什么 |
| --- | --- |
| 概览 | 距 2027 年 3 月校考倒计时、题库完成度环形图、今日任务打卡、正确率统计 |
| 院校库 | 52 所湖南单招院校，按城市 / 办学性质筛选 + 关键词搜索；详情含简介、优势专业、考试形式、报考提示，可收藏 |
| 刷题 | 语文 / 数学 / 英语 / 职业适应性测试共 51 题，即时判分 + 解析；支持顺序练习、随机 10 题模拟、错题重做 |
| 错题本 | 答错自动收录，重做答对自动移出，也可手动增删 |
| 备考指南 | 一年备考时间轴 + 单招常见问题 |

## 本地运行

单文件，直接双击 `index.html` 即可。想用本地服务器：

```bash
python3 -m http.server 7788
# 打开 http://127.0.0.1:7788
```

学习进度（收藏、错题、答题记录、打卡）存放在浏览器 `localStorage`，键名统一带 `hndz27:` 前缀，换浏览器不会同步。

## 目录结构

```
.
├── index.html              # 站点全部内容：结构 + 样式 + 数据 + 逻辑
├── README.md
└── .github/workflows/
    └── deploy.yml          # 推送 main 分支即自动部署到 GitHub Pages
```

## 部署

仓库已配置 GitHub Actions：向 `main` 分支推送后自动构建并发布到 GitHub Pages，无需手动上传产物。

```bash
git add .
git commit -m "feat: 更新题库"
git push
```

首次部署需要仓库 Settings → Pages → Source 选 **GitHub Actions**（工作流里的 `configure-pages` 已带 `enablement: true`，一般会自动开启）。

## 数据说明

院校简介、优势专业、考试形式为备考整理版本，**招生专业、计划数、录取规则、体检要求请以湖南省教育考试院及各校当年官方招生简章为准**。倒计时锚定的 2027-03-20 为按往年 3 月中下旬校考节奏预估，官方公告后修改 `index.html` 中的 `EXAM_DATE` 即可。
